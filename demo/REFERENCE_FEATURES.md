# 参考图特征与本次调整

参考：用户提供的等待室布局图、Loop 1 四阶段空间层级图；仅作为设计参考，未复制为游戏贴图。

| 可见特征 | 工程中的实现 |
| --- | --- |
| 四阶段中始终是同一个封闭房间，墙角和墙脚保持相接 | 六面外壳使用相同边界采样，全部顶点经过同一空间映射 |
| 地砖在后期出现斜向拉长、压窄，方向随位置改变 | 地板也参与变形；砖缝在原始坐标生成，跟随网格连续拉伸 |
| 后墙的公告板、钟和柜子明显倾斜，出口保持不同的局部方向 | 按深度变化的剪切、压缩和弯曲；局部变形导数随位置变化 |
| 灯具和天花板同向贴合；家具仍与墙、地板保持布局关系 | 家具、灯具、文字和交互位置跟随同一映射；没有额外旋转墙板 |
| 变化渐进，后期更强 | 十分钟内非线性增加强度；1–4 可定格对比 |
| 房间在失控前变得狭窄，保持玩家的体量参照 | 宽度与深度各收缩约 38%，高度收缩约 20%；玩家眼高不缩放，家具保留尺寸参照 |

镜头保持第一人称，不使用整屏倾斜或改变 FOV 制造效果。当前是实际房间收缩与连续几何变形带来的透视变化；并非多个独立投影同时渲染。
家具与材质保留简化版本，重点验证连接、拉伸和可玩性。
