## 自己调颜色和亮度

1. 墙色：打开 `assets/materials/user_wall_20261029/Plaster.tres`，修改 Albedo / Color。颜色乘数包含对棕色原图的补偿；调整前请保留备份。
2. 全局亮度：打开 `room_decor.scn`，选择 `IndoorEnvironment`，展开 Environment → Tonemap → Exposure。当前 1.15，可少量尝试降低；它会同时影响暗部。
3. 在本地场景中修改并保存，按 F5 运行完整项目验证；运行时的远程修改通常不会持久保存。
