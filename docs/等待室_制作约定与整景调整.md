## 三、完整场景接入

### 地板与照明

- 将 v04 已确认的旧釉砖材质、砖缝、磨损与反光层次应用到完整房间。
- 保留材质的颜色、粗糙度与法线数据；地面不使用自发光模拟反光。
- 按完整房间的尺寸、入口、出口和灯具位置重新布光与烘焙，不机械复制局部样板的灯光数值。
- 灯泡的可见发光、照向场景的实际光源、反弹光和表面反射分别正确设置。
- 以 Godot 实际运行画面验收；Cycles 图用于参考，不能代替游戏画面。
- 延续已验证的地砖侧面 UV 与实时阴影修复，检查反射黑斑、发白砖缝和阴影条纹是否复发。

### 挂钟与壁灯

- 依照参考图主体画面调整比例、相互间距和墙面位置，不依据参考图右下角的错误示意图重新摆放。
- 钟面数字加大、加粗、保持清晰美观；避免灯光和反射盖过数字及指针。
- 调整小壁灯的灯罩比例、安装方式、照射方向、暖光范围和衰减，使其与老旧办公空间一致。
- 保留独立部件：`Clock_Frame`、`Clock_Face`、`Clock_HourHand`、`Clock_MinuteHand`、`Clock_Pivot`、`Clock_Back`。
- 时针、分针分别旋转；后续 Loop 4 使用同一款钟放大复制，不再另做款式。
- 不将钟表部件与壁灯或其他资产合并，避免交互、缩放和阴影处理互相牵连。

### 保留的其他修改事项

- 处理桌面道具、纸张、墙面标牌与开关的悬浮、穿插和接触问题。
- 调整入口门、门框和开关；入口旁的小灯根据整体布光决定保留或移除。
- 柜体减薄，同时保留可进入的内部与镜面通道；旁边补一个正常储物柜。
- 调整纸质标签与箱子摆放，移除用户指出的右侧红色标识箱。
- 重做更自然的 EXIT 标志。
- 公告板与挂钟适度左移；按整体构图裁减空余区域。
- 公告板维持 **6 张主要公告 + 1 张关键便签**，不添加额外普通便签。
- 关键便签自然贴在公告板上，可以压住邻近纸张的一小部分。当前文字为 **17:3**，后续状态为 **17:30 → 18:40**；位置、颜色和大小不随文字状态改变。
- 原有家具和材质以保留为原则；调整遵循此前已授权的归位范围。
